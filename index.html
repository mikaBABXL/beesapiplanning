Synchronisation Cloud — JSONBin.io

Toutes les données sont partagées en temps réel entre l'admin et les employés via JSONBin.io (gratuit). Entrez votre clé API et l'ID du bin ci-dessous.

📋 Étapes :
1. Créez un compte gratuit sur jsonbin.io
2. Allez dans API Keys → copiez votre clé secrète
3. Cliquez "Créer le Bin" ci-dessous (une seule fois)
4. Cliquez "Sauvegarder" — c'est tout !

📥 Import / 📤 Export Planning

Format CSV attendu : Jour, Date, Stand, Shift, Horaire, Employé, Confirmé
Séparateur : virgule ou point-virgule — Encodage : UTF-8

👤 Comptes utilisateurs

Les comptes sont définis dans le code. Le mot de passe de chaque employé correspond à son prénom en minuscules + Biorich2026 (exemple : elie → elieBiorich2026). Modifiez le tableau USERS dans le code HTML pour ajouter/modifier des comptes.
